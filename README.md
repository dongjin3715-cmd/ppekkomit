# 빼꼼잇

화면 가장자리에 인덱스 포스트잇처럼 **빼꼼** 튀어나와 있는 윈도우용 메모 앱이에요.
탭을 누르면 메모가 스르륵 펼쳐지고, 다시 누르면 쏙 들어가요.

## ⬇️ 다운로드

**[최신 버전 받기 (Ppekkomit.exe)](https://github.com/dongjin3715-cmd/ppekkomit/releases/latest/download/Ppekkomit.exe)**

모든 버전: [Releases](https://github.com/dongjin3715-cmd/ppekkomit/releases)

## 설치

1. `Ppekkomit.exe`를 계속 둘 폴더(예: `C:\Users\내이름\빼꼼잇\`)에 넣고 더블클릭하세요. 설치 과정은 없어요.
2. **"Windows의 PC 보호"** (SmartScreen) 창이 뜨면, 서명되지 않은 프로그램이라서 그래요.
   **추가 정보 → 실행**을 눌러 주세요.
3. 화면 가장자리에 메모 탭이 빼꼼 나오면 성공! 트레이 아이콘을 오른쪽 클릭하면 메뉴가 나와요.

## 주요 기능

- 화면 가장자리에 붙는 인덱스 탭 메모
- 메모마다 제목, 색상, 무늬
- 체크리스트 (Ctrl+L), 취소선 (Ctrl+D), 새 메모 (Ctrl+N)
- 자동 저장, 윈도우 시작 시 자동 실행

## 🔄 자동 업데이트

빼꼼잇은 켜져 있는 동안 6시간마다 새 버전을 확인하고, 있으면 알아서 바꾼 뒤 다시 실행돼요.
트레이 메뉴의 **업데이트 확인**으로 바로 확인할 수도 있어요.
메모는 `%APPDATA%\StickyMemo\memos.json`에 저장돼서 업데이트해도 그대로 남아요.

필요 환경: Windows 10 / 11 (.NET Framework 4.x 기본 포함)
